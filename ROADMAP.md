# Roadmap — League of Spirit (LOST)

Функционал по блокам. Дробим на мелкие задачи, двигаемся к MVP → полноценному продукту.
Обязательные блоки — Дизайн и Разработка. Прочие добавим после анализа масштабов.

## Дизайн

### MVP
- [ ] Обновлённый брендбук (сначала — продуманная система генерации, потом сам брендбук)
- [ ] Графика на трансляции: базовый набор (HUD, оверлеи, плашки)

### После MVP
- [ ] Полное оформление сезона под команды
- [ ] Развитая графика трансляции по референсам (Paragon / BetBoom / ESL)

## Разработка

### MVP — генеративный пайплайн (делаем первым, хорошо продумать)
- [ ] Генерация логотипов команд
- [ ] Генерация оформления команд
- [ ] Генерация превью и баннеров
- [ ] Генерация отдельных элементов граффити
- [ ] Обработка фото
- [ ] Генерация презентаций для партнёров

### MVP — контент-цикл игрового дня
Поток: **анонс → лайв со студийным деском → highlights + shorts → пост-матч + MVP**.
- [ ] Анонсы игр
- [ ] Лайв: студийный деск (драфт / аналитика / пост-матч разбор)
- [ ] Highlights + shorts (клипы эпик-моментов — под охваты)
- [ ] Анонсы результатов + корректировка таблиц
- [ ] Инфографика по игре через OpenDota API
- [ ] Админка (на лендинге): назначение MVP + начисление баллов
- [ ] Админка: баллы кастеру / стримеру

> Дев-спека операционной системы (данные / флоу / треккинг, этапы) — [ARCHITECTURE.md](./ARCHITECTURE.md).

### После MVP
- [ ] Внедрить HUD **LHM.gg** — лайв-статы (урон, лагеря, золото, Рошан) готовым инструментом, не разработкой; проверить цену/лицензию/кастомизацию

## Прочие блоки
