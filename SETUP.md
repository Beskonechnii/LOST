# Как запустить проект на новом компьютере

Инструкция для новичка. Просто повторяй по шагам.

## Шаг 1. Поставь две программы

1. **Node.js** — скачай с [nodejs.org](https://nodejs.org), кнопка **LTS**. Установи, нажимая «Далее».
2. **Git** — скачай с [git-scm.com](https://git-scm.com/downloads). Установи так же.

После установки **перезагрузи компьютер**.

## Шаг 2. Открой терминал

- **Windows:** нажми `Win + R`, напечатай `cmd`, нажми Enter.
- **Mac:** нажми `Cmd + Пробел`, напечатай `Terminal`, нажми Enter.

Появится чёрное (или белое) окно, куда можно печатать команды.

## Шаг 3. Скопируй проект

Вставь эту строчку в терминал и нажми Enter:

```
git clone https://github.com/Beskonechnii/LOST.git
```

Потом эту:

```
cd LOST/web
```

## Шаг 4. Подготовь настройки

- **Windows:**
  ```
  copy .env.example .env
  ```
- **Mac:**
  ```
  cp .env.example .env
  ```

## Шаг 5. Установи всё нужное

Вставь по очереди, каждую строчку с Enter (первая может подумать пару минут):

```
npm install
```

```
npx prisma migrate deploy
```

## Шаг 6. Запусти

```
npm run dev
```

Когда появится строчка **`http://localhost:3000`** — открой её в браузере. Готово 🎉

Чтобы остановить — нажми в терминале `Ctrl + C`.

---

**Если запускаешь во второй раз** — не нужно всё заново. Открой терминал, зайди в папку
и запусти:

```
cd LOST/web
```

```
npm run dev
```
