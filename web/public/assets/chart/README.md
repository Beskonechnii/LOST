# Подложка графика преимущества

Сюда кладётся один файл:

```
public/assets/chart/bg.png
```

Правила — как у подложек шаблонов студии (`public/templates/*/bg.png`):

- Показывается только внутри области графика (`AdvantageChart` в `_components/postgame/blocks.tsx`),
  растягивается на всю её ширину/высоту с обрезкой по краям (`preserveAspectRatio="xMidYMid slice"`) —
  подойдёт любой формат, важна общая тональность, а не точные пропорции.
- Рисуется поверх фирменного градиента-заглушки с затемнением сверху — держите картинку неконтрастной
  и без текста, иначе поплывёт читаемость сетки, подписей и линий золота/опыта.
- Пока файла нет, график работает и без подложки — только на градиенте-заглушке.
