# Логотипы партнёров плашки постгейма

Плашка внизу экспортных картинок сейчас — часть подложки `public/templates/postgame/bg.png`
целиком (растровая, склеена дизайнером). Логотипы там мельче лого LOST, а перерисовать
именно эту часть картинки, не трогая остальное, без исходных слоёв нельзя.

Решение — вынести плашку в вёрстку (React/SVG поверх подложки), тогда размер каждого лого
задаётся кодом и его легко подогнать под LOST. Для этого нужны отдельные файлы:

```
public/assets/partners/na-dne.png
public/assets/partners/collectors-shop.png
public/assets/partners/miller.png
public/assets/partners/gorilla.png
```

Названия файлов — ориентир, важно по одному PNG на партнёра (остальных участников — LOST S2
и League of Spirits — трогать не нужно, они уже соразмерны).

Правила:

- **PNG с прозрачным фоном**, логотип белым/светлым — как остальные элементы плашки
  (На картинке-примере они уже белые/монохромные).
- Разрешение с запасом (плашка идёт в экспорт 1920×1080) — высота хотя бы 200px.
- Если есть возможность — заодно попроси у дизайнера версию `bg.png` **без** текущей плашки
  партнёров внизу (только фон/геометрия/лого LOST), иначе новая плашка будет рисоваться
  поверх старой мелкой и они наложатся друг на друга.
