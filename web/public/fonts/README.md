# Шрифты редактора

Сюда кладём файлы шрифтов для конструктора графики (`/studio/editor`).

## Как добавить шрифт

Просто **положи файл в эту папку** — `.woff2` (лучше всего), `.woff`, `.ttf` или `.otf`.
Редактор сам его подхватит: при открытии документа сервер читает папку, и шрифт появляется
в списке «Шрифт» у текстовых элементов. Дописывать ничего не нужно.

- **Имя в списке** берётся из имени файла: `druk-wide.woff2` → «Druk Wide».
- **Начертание** распознаётся из имени, если оно там есть: `...-bold`, `...-700`, `...-light`
  и т.п. Иначе шрифт считается обычным.
- Один файл = одно начертание. Нужны разные веса — клади несколько файлов
  (`inter-regular.woff2`, `inter-bold.woff2`).

Шрифт попадает и в PNG-экспорт (снимок инлайнит подключённые шрифты).

Файлы шрифтов **коммитятся** — это ассеты релиза, как иконки и лого (папка вне `uploads/`,
в `.gitignore` не входит).
