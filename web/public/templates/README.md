# Подложки шаблонов студии

Сюда кладутся фоны, экспортированные из Figma/PSD, — по папке на шаблон:

```
public/templates/vs-announce/bg.png   1920×1080
public/templates/match-day/bg.png     1080×1920
```

Правила:

- **PNG в натуральном размере шаблона** (id шаблона = имя папки, см. `src/studio/registry.ts`).
- **Без текста и без логотипов команд** — всё это рисует вёрстка поверх. На фоне остаются только
  постоянные элементы: свечение, дым, геометрия, лого лиги и спонсорские слоты.
- Пока файла нет, шаблон рисует фирменный градиент-заглушку — студия работает и без подложки.
